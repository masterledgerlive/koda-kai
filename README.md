# Koda Kai 🌊

The kid-safe personal operating system. *Koda* (Dakota: friend, ally) + *Kai* (Hawaiian: sea, ocean) — be like water, my friend.

**"KODA is the friend, KAI is the sea — let knowledge and love reshape your heart, body, mind and soul; explore and learn."**

## What it is

A single-file web app (`koda-kai.html`) for kids — no accounts, no ads, nothing exits to the outside without the parent PIN:

- **Watch** — Dad's Mix, Kai's TV (approved channels), My List, channel shuffle, read-along word captions
- **Learn** — Learning Room + PIN-gated Monster Reader handoff
- **Story Studio** — ad-lib story maker, puppet storybook stage, Draw canvas
- **Quests & Discoveries** — photo quests, token-earning recognition loop, growing map
- **Band Room** — instruments in the clouds: tap, record, layer
- **Chat / Walkie-talkie** — safe family messaging, push-to-talk fun
- **My Things** — keepsake/item tracking
- **Learning Book** — the app's memory of everything the kid does (export it to keep it for years)

## Run it

Open `koda-kai.html` in any browser, or serve this folder:

```bash
python3 -m http.server 8000
```
